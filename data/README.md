# 数据说明

本目录只保留**聚合结果、数据来源说明和核验摘要**，不含原始气象输入、逐日调度记录、模型检查点或实验协议。

## 文件与内容

| 文件 | 内容 |
|---|---|
| `main_case_summary.csv` | 普通日增广与等权压力增广的10种子均值，包含平均成本、T95、ES95和日均缺水。 |
| `network_budget_summary.csv` | 2个网络、3类网络工况、4档预算的24组汇总结果。 |
| `capacity_summary.csv` | 不同时窗与库容配置的4行复核结果。 |
| `paired_method_summary.csv` | 4档预算下压力增广与问题驱动削减的配对统计。 |
| `external_replay_summary.csv` | 元谋和 Kericho 的4组全年汇总，含两方案 T95、缺水及差值。 |
| `external_difference_stats.csv` | 外部全年差值的均值、中位数、四分位数和正/零/负种子数。 |
| `verification_summary.json` | 测试、数字复核、外部回放和图件一致性检查的摘要。 |

## 数据来源与处理

### 合成场景

合成光伏、需水、设备及网络场景用于主要调度实验。每个种子使用60个训练日和200个独立测试日，种子为42—51。场景生成、增广和回放均按固定随机流执行。公开 CSV 为聚合后的结果，不是原始逐日输入。

### 元谋站观测

- 元谋干热河谷站气象观测数据集（含太阳辐射）（2019—2022）：DOI [10.12380/Meteo.msdc.000059](https://doi.org/10.12380/Meteo.msdc.000059)。
- 元谋干热河谷站常规气象观测数据集（2022—2026）：DOI [10.12380/Meteo.msdc.000060](https://doi.org/10.12380/Meteo.msdc.000060)。
- 来源：山地科学数据中心；逐时记录；许可为 CC BY 4.0，使用时须署名。
- 用途：站点气象、参考蒸散和设计需水标尺的观测级对照，**不等于园区田间实测**。

### ERA5 / ERA5-Seamless

通过 Open-Meteo Historical Weather API 获取元谋与 Kericho 的再分析驱动，包括逐时短波辐射、气温、降水和风速等。元谋使用2022—2023年训练、2025年测试；Kericho使用2022—2023年训练、2024年测试。公开文件仅含全年及季度聚合结果，原始响应和逐时输入不公开。数据使用遵循 Open-Meteo 条款及 CC BY 4.0。

### 配电网模型

使用 IEEE 33节点和 IEEE 69节点仿真网络及8个园区接入关系。规划层使用 LinDistFlow 电压约束，执行后进行逐时交流潮流复核。网络模型不是现场实测配电系统。

## 指标与单位

- **T95**：成本的95%分位数，先在每个种子的测试日计算，再按说明跨种子汇总。
- **ES95**：最差5%测试日成本的均值。
- **m / M**：基础条目数 / 增广后的最终条目数。
- **差值方向**：`rank - uniform`，正值表示压力增广方案的成本或缺水更低。
- **外部描述性统计**：四分位区间描述10个种子的差值分布，不是置信区间，也不据此声称普遍显著占优。
- **成本**：元/日；**水量**：m³/日；**功率**：kW；**时间分辨率**：1小时。
